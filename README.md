# GOA 서버 설치기

윈도우와 맥에서 동작하는 모드 설치기입니다. 친구들은 설치기를 실행하고 버튼만 누르면 돼요.

## 1. 설정
`installer.py` 위쪽의 `MANIFEST_URL`, `SERVER_ADDRESS` 를 본인 값으로 바꿔요.

## 2. 배포용 파일 준비
```
pack/
  mods/        ← 보이스모드, 저니맵 등
  shaderpacks/ ← 쉐이더팩 zip
  config/      ← 필요한 설정 파일
```
이 `pack` 폴더를 웹(GitHub Releases, 개인 호스팅 등)에 그대로 올려요.
```
python make_manifest.py ./pack https://내주소/files 21.11.0
```
마지막 값은 NeoForge 버전이에요. 만들어진 `manifest.json` 도 `MANIFEST_URL` 주소에 올려요.

## 3. 빌드
각 OS 에서 만들어야 해서 GitHub 에 올린 뒤 Actions 의 `build-installer` 를 실행하면 윈도우 exe, 맥 app 이 같이 만들어져요.

## 4. 친구들이 할 일
1. 공식 마인크래프트 런처를 한 번 실행해서 로그인
2. 설치기 실행 → 설치 / 업데이트
3. 런처에서 "GOA 서버" 프로필로 플레이

## 업데이트할 때
`pack` 폴더를 고치고 `make_manifest.py` 를 다시 실행해서 올리면 끝. 친구들은 설치기를 다시 누르면 바뀐 파일만 받아요.

## 알아둘 점
- 서명이 없는 앱이라 윈도우는 "알 수 없는 게시자", 맥은 "확인되지 않은 개발자" 경고가 떠요. 윈도우는 추가 정보 → 실행, 맥은 앱을 우클릭 → 열기로 넘어가면 돼요.
- GitHub 의 맥 빌드는 애플 실리콘(M 시리즈) 기준이에요. 인텔 맥이 있으면 따로 대응이 필요해요.
- NeoForge 설치 옵션과 버전은 실제 환경에서 한 번 테스트해보세요. 안 되면 오류 메시지가 창에 나와요.
